怎么装

整个包装下来 12.6 MB，从头到尾不用敲一行命令。

  1. 解压得到一个「内容直贴-本地组件」文件夹。
  2. 双击 Paste2DocSetup.exe选个安装位置（默认装在当前用户下， 不需要管理员权限），点「安装」，几秒钟就好。
  3. 回侧边栏点「重新检测」状态变成「已连接」就能用了。 如果扩展是后装的，再打开一次安装程序就行 —— 它会重新扫一遍扩展 ID。
只装这个不够用。本地组件只负责「粘出格式」，框选和提取在扩展里。 扩展本体请回主页下载完整包。

它是什么

它做什么接收扩展算好的内容，写成 docx（塞进 Kingsoft WPS 9.0 Format）和 RTF（塞进 Rich Text Format），再放一份纯文本
它不做什么不联网、不读文件、不执行命令、不开机自启、不常驻（空闲几十秒自己退出）
需要什么Windows 10 / 11，装上就能用 —— 运行环境已经打在 exe 里，不用先装 Python
怎么确认通了侧边栏右上角显示「已连接」；粘一次到 WPS，字体、缩进、公式都在就是通了
怎么卸载「设置 → 应用 → 已安装的应用」里找到「内容直贴 · 本地组件」点卸载； 或者重新打开 Paste2DocSetup.exe，里面有卸载
装在哪儿默认 %LOCALAPPDATA%\Paste2Doc，安装时可以改。登记只写 HKCU（当前用户）

常见问题

侧边栏一直显示「未安装」
先确认安装程序最后一行是「装好了」。装完必须把浏览器完全关掉再开 —— 浏览器只在启动时读宿主清单。 如果还是不行，把浏览器重开后再双击一次安装程序（它会重扫扩展 ID）。
装完自检能过，但粘到 WPS 里还是纯文本
那是白名单里没有当前这个扩展的 ID：商店版的 ID 和开发者版不一样。双击一次安装程序即可。
要不要先装 Python
不用。安装包是自带运行环境的单文件程序，跟普通软件一样双击就装。 完全不想装也可以：扩展照样能用，只是内容以纯文本进剪贴板，粘到 WPS 里得自己调字体。
Windows 说「已保护你的电脑」
那是 SmartScreen 对没有代码签名的新程序的一贯提示。点「更多信息 → 仍要运行」即可。 这不是病毒提示：程序不联网、不起服务、不加开机启动，装完只在 %LOCALAPPDATA% 和注册表当前用户下留东西。
