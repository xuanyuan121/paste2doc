三种粒度，各管一层

以前的问题不是"能不能复制"，是复制出来大小不受控：想复制一段，结果带出半条回答； 想复制整条，结果只框住一段。

全文

指在这条回答的任意位置——正文、段间空白、右边距——框的永远是整条回答。 页面顶栏、输入框、底部「复制 / 重试 / 朗读」那排按钮不算正文，指上去不画框。

单段

只框你指到的那一块：一个段落、一条分点、一张表、一段代码、一个公式。 分点列表按「条」切，点第二条就只复制第二条。

区间

点第一下定开头，点第二下定结尾，第二下点完就直接进剪贴板——没有确认这一步。 中间那几块原样保留结构。

指在空白上什么都不框，这是刻意的：鼠标划过段与段之间的缝时不会闪框， 也不会误复制。复制完不用回侧边栏，接着点下一条就行。

默认就是你要的排版

网页上的格式一律不进文档，除非你主动选「保留原格式」。

中文字体宋体
英文与数字Times New Roman
字号 · 行距五号（10.5pt）· 单倍行距
段落首行缩进两字
清理去掉网页的局部加粗、斜体、彩色字、行内底色，只保留标题与表头是粗体
结构标题分级、有序/无序列表（编号接续）、表格（可编辑）、代码块（等宽 + 缩进）、公式（原生可编辑）
字号、行距、首行缩进都能在侧边栏里改；也能一键切换成「保留原格式」或「只复制纯文本」。

装它，四步

下载包里有 使用说明.txt，下面是一样的内容。

  1. 下载并解压解压出来是一个文件夹（这一层能直接看到 manifest.json）。
  2. 加载扩展打开 edge://extensions（Chrome 是 chrome://extensions）， 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选中刚才那个文件夹。
  3. 装本地组件解压后双击 host\安装本地组件.bat。 它把本地组件注册到当前用户下，不需要管理员权限；本机没有 Python 的话，它会问你要从哪个源下载并自动装好。 装完回扩展页点一下「重新加载」。也可以在侧边栏点「下载本地组件」单独下这一包。
  4. 开始用点工具栏图标打开侧边栏 → 点「开始使用」→ 选一种方式 → 在页面上点一下 → 去 WPS 里 Ctrl+V。

关于那个「本地组件」

WPS 文字只接受它自己专用的剪贴板格式，浏览器没有写入这种格式的接口，所以需要一个很小的本地程序代写一下。 Word 不需要它。单独下载本地组件 →

它做什么只做一件事：把已经算好的、排好版的内容写进剪贴板
它不做什么不联网、不读文件、不执行命令、不开机自启、不常驻（空闲一会儿就退出）
需要什么Python 3.8 以上。没有也行 —— 安装程序会问你要不要下一个（华为云 / npmmirror / 官方），带进度条自动装好
怎么确认通了双击 host\自检.bat，它会检查一遍并往剪贴板里放一份样例，粘到 WPS 里看看就行

它不做什么

这些是设计时就定死的，不是"以后再补"。

不联网

运行时不发任何网络请求：没有账号、没有统计、没有远程配置、没有远程代码。 公式渲染用的 KaTeX 打包在扩展里，不从 CDN 加载。 唯一的例外是你主动点侧边栏的「下载本地组件」——那一下会去我们的下载页取那个安装包。

不碰你的内容

只在你点击之后读取你选中的那一段，用来生成文档。 不读剪贴板里已有的内容，不收集浏览记录。

不动页面

不挂悬浮按钮，不插入任何元素。关掉之后页面完全不受影响； 开着的时候也只有指到正文的那一下点击会被接管，页面自己的按钮照常能点。
